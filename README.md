# EC120 MCQ drill

240 practice multiple-choice questions for EC120 (lectures 1-8), as a single page.

**Use it:** https://daniyalmughal1.github.io/ec120-mcq-drill/

- Pick all 240 or one lecture, and a round size (all, 10, 20, 40). Questions come in random order.
- Wrong answers go on a missed list saved in your browser. Pick "My missed questions" to redo them; a question drops off once you get it right.
- Keys: 1-4 or A-D to answer, Enter for next.

The missed list lives in the browser you use, so it doesn't sync between devices.

This is an original practice bank, not an official exam.
